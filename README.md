# Life-OS: AI-Powered Personal Dashboard

An advanced, full-stack Next.js web application designed to act as a personal operating system. Features an AI-driven coaching assistant (Dex), habit tracking, mood analytics, and real-time autonomous job application tracking.

## Tech Stack
- **Frontend:** Next.js, React, TailwindCSS, Framer Motion
- **Backend:** Supabase, Next.js API Routes
- **AI Integration:** Claude 3.5 Sonnet / OpenAI APIs for intelligent morning briefings and goal tracking.

## Features
- 🤖 **Dex AI Coach:** Context-aware LLM coach for daily motivation and habit optimization.
- 🎯 **Job Pipeline Tracker:** Real-time metrics tracking autonomous application engine success rates and rejections.
- 📈 **Data Visualization:** Mood and energy correlation charts built with custom SVGs.
